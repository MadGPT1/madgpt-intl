Agen AI untuk VS Code yang bekerja di seluruh repositori

Asisten kode ada banyak, tetapi kebanyakan berhenti di satu fungsi. Agent Mode di MadGPT Coder melihat seluruh proyek Anda: menyusun rencana, membaca file, dan mengubahnya.

Apa yang dilakukannya

  • Rencana dulu, baru kode. Ia menjelaskan dulu file mana yang akan diubah dan alasannya.
  • Perubahan di seluruh repositori. Beberapa file sekaligus dalam satu tugas.
  • Tinjauan keamanan dan refaktor. Mencari bug, mengaudit, dan merapikan kode lama.
  • Beberapa kunci API, masing-masing dengan batas harian. Beri akses ke tim tanpa membagikan akun Anda.

Cara memulai

  • Pasang ekstensi di VS Code, masukkan kunci MadGPT Anda, lalu tulis tugasnya dengan bahasa biasa. Agen mengerjakan sisanya di dalam editor. Agent Mode termasuk dalam paket Lifetime.

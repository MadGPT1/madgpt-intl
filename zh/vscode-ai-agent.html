一个能在整个仓库上工作的 VS Code AI 智能体

代码助手很多，但大多只盯着一个函数。MadGPT Coder 的 Agent Mode 看的是你的整个项目——它制定计划、读取并修改文件。

它能做什么

  • 先计划，再写代码。 会先说明要改哪些文件、为什么。
  • 跨整个仓库修改。 在一个任务里同时改动多个文件。
  • 安全审查与重构。 找 bug、做审计、清理老旧代码。
  • 多个 API 密钥，各有每日额度。 分享访问权限，而不必共用账号。

如何开始

  • 在 VS Code 里装上扩展，填入你的 MadGPT 密钥，用大白话写出任务。智能体就在编辑器里完成其余工作。Agent Mode 包含在 Lifetime 套餐中。

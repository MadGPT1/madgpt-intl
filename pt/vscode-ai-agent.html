Um agente de IA para VS Code que trabalha no repositório inteiro

Existem muitos assistentes de código, mas a maioria fica em uma função. O Agent Mode do MadGPT Coder olha o projeto inteiro: monta um plano, lê os arquivos e faz as alterações.

O que ele faz

  • Primeiro o plano, depois o código. Antes ele explica quais arquivos vai mudar e por quê.
  • Alterações em todo o repositório. Vários arquivos de uma vez dentro da mesma tarefa.
  • Revisão de segurança e refatoração. Encontra bugs, audita e limpa código antigo.
  • Várias chaves de API, cada uma com limite diário. Dê acesso à equipe sem compartilhar sua conta.

Como começar

  • Instale a extensão no VS Code, informe sua chave do MadGPT e descreva a tarefa em palavras simples. O agente faz o resto dentro do editor. O Agent Mode está incluído no plano Lifetime.

Perguntas frequentes

Ele lê meu repositório inteiro?

Sim, o Agent Mode trabalha entre arquivos, não em uma única linha.

Dá conta de projetos grandes?

Sim, ele lembra a estrutura de sessões longas e de bases de código grandes.

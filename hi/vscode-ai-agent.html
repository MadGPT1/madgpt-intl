VS Code के लिए एक AI एजेंट जो पूरी रिपॉज़िटरी पर काम करता है

कोड सहायक बहुत हैं, पर ज़्यादातर एक फ़ंक्शन तक सीमित रहते हैं। MadGPT Coder का Agent Mode आपके पूरे प्रोजेक्ट को देखता है — प्लान बनाता है, फ़ाइलें पढ़ता है और बदलता है।

यह क्या करता है

  • पहले प्लान, फिर कोड। किन फ़ाइलों को क्यों बदलेगा, पहले बताता है।
  • पूरी रिपॉज़िटरी में बदलाव। कई फ़ाइलों में एक साथ, एक ही टास्क के तहत।
  • सिक्योरिटी रिव्यू और रिफैक्टर। बग ढूँढना, ऑडिट और पुराने कोड को साफ़ करना।
  • कई API की, हर एक पर रोज़ की लिमिट। टीम को ऐक्सेस दें बिना अपना अकाउंट शेयर किए।

कैसे शुरू करें

  • VS Code में एक्सटेंशन जोड़िए, अपनी MadGPT की डालिए, और सादे शब्दों में टास्क लिखिए। एजेंट बाकी एडिटर में ही कर देता है। Agent Mode, Lifetime प्लान में शामिल है।

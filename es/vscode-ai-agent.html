Un agente de IA para VS Code que trabaja en todo el repositorio

Hay muchos asistentes de código, pero la mayoría se queda en una función. Agent Mode de MadGPT Coder mira todo tu proyecto: hace un plan, lee los archivos y los modifica.

Qué hace

  • Primero el plan, luego el código. Antes explica qué archivos va a cambiar y por qué.
  • Cambios en todo el repositorio. Varios archivos a la vez dentro de una misma tarea.
  • Revisión de seguridad y refactorización. Busca errores, audita y limpia código antiguo.
  • Varias claves de API, cada una con su límite diario. Da acceso al equipo sin compartir tu cuenta.

Cómo empezar

  • Instala la extensión en VS Code, introduce tu clave de MadGPT y describe la tarea con palabras normales. El agente hace el resto dentro del editor. Agent Mode está incluido en el plan Lifetime.

Preguntas frecuentes

¿Lee todo mi repositorio?

Sí, Agent Mode trabaja entre archivos, no en una sola línea.

¿Puede con proyectos grandes?

Sí, recuerda la estructura de sesiones largas y bases de código grandes.
